# BTCUSD Market Mechanics Lab

Standalone interactive trade-flow research dashboard for exploring BTCUSD price action, executed volume, signed flow, CVD, and event follow-through.

## Use

Open `BTCUSD_Market_Mechanics_Lab_Fixed.html` in a modern browser. Import additional daily CSV or ZIP trade files for multi-day analysis. The embedded sample data covers September 1, 2026 only.

See `BTCUSD_Market_Mechanics_Fix_Report.md` for the accuracy audit, corrections, validation notes, and remaining source-data limitations.
